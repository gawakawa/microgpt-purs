# vocabSize 計算バグの修正

## 問題

`numSteps=1` のテスト中に断続的なエラーが発生していた。

```
TypeError: Cannot read properties of undefined (reading 'length')
```

ランダムシャッフルの結果によってエラーが出たり出なかったりする非決定的な挙動。

### 原因

`Main.purs` の `vocabSize` 計算が間違っていた。

```purescript
vocabSize = length (buildVocab dataset) + 1  -- unique chars の数
```

`encode` は ASCII 位置でトークン化する:

```purescript
encode c = Token $ on (-) toCharCode c 'a'  -- 'a'→0, 'e'→4, 'm'→12, 'z'→25
bos = Token 26
```

例: データセットが "emma" のみの場合:
- `buildVocab` = ['a', 'e', 'm'] → 3文字
- `vocabSize = 4`
- `wte` は 4行（インデックス 0-3）
- しかし 'e' → Token 4 → 範囲外アクセス

## 解決策

トークンの最大値から `vocabSize` を計算するよう修正。

### 変更点

1. `buildVocab` のインポートを `bos` に変更
2. `Data.Newtype (unwrap)` を追加
3. `vocabSize` の計算式を修正

### コード

```purescript
-- 旧
import Tokenizer (buildVocab)
let vocabSize = length (buildVocab dataset) + 1

-- 新
import Tokenizer (bos)
import Data.Newtype (unwrap)
let vocabSize = unwrap bos + 1  -- = 27
```

## 検証結果

- ビルド: 成功
- テスト: 成功
- 断続的エラー: 解消
- 実行時間 (`numSteps=1`): 約70-130秒
